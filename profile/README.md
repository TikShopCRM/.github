## Що ми створюємо

TikShopCRM розробляється для блогерів, Telegram-магазинів і продавців, які отримують замовлення під час TikTok-трансляцій.

Замість повідомлень, таблиць і ручного перенесення даних — одна система, в якій видно товар, покупця, оплату, доставку та поточний стан замовлення.
