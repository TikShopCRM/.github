## Що таке TikShopCRM?

**TikShopCRM** — система для блогерів і продавців, які приймають замовлення через TikTok, Telegram та прямі трансляції.

Покупець вибирає товари, менеджер перевіряє замовлення, система допомагає прийняти оплату, оформити доставку та повідомити клієнта.
