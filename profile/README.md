## Від коментаря до відправлення

Продажі через TikTok і Telegram часто починаються з простого повідомлення, але далі з’являються уточнення, записи в таблицях, перевірка оплати та ручне оформлення доставки.

TikShopCRM збирає ці етапи в один послідовний процес:

<div align="center">

### Товар → Замовлення → Підтвердження → Оплата → Доставка

</div>

Покупець оформлює замовлення через Telegram Mini App, а менеджер одразу отримує товари, контактні дані та інформацію для відправлення.

## Більше ніж список замовлень

TikShopCRM створюється як повноцінний робочий простір для продавця та його команди:

* оформлення замовлень через Telegram Mini App;
* створення замовлення зі списку товарів або фотографії;
* робота з фактичною вагою,ю та остаточною ціною;
* база клієнтів та історія покупок;
* промокоди й накопичувальні знижки;
* підключення оплати та служб доставки;
* статистика продажів і популярних товарів.

<br>

## Для кого створюється TikShopCRM

Для блогерів, Telegram-магазинів, невеликих брендів і продавців, які приймають замовлення під час TikTok-трансляцій.

Система має залишатися простою для невеликої команди, але давати достатньо можливостей для зростання магазину.
